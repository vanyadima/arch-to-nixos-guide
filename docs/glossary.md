# Приложение. Глоссарий терминов

> **Навигация:** [🏠 Оглавление](../README.md#-содержание) · [⬅ Предыдущая часть](06-problemy-i-zaklyuchenie.md)

---

Список терминов, которые встречаются в гайде. Будет пополняться по мере написания глав.

| Термин | Краткое объяснение |
|---|---|
| **Derivation** | Описание того, как собрать пакет: из чего и какими шагами |
| **Flake** | Способ описать конфигурацию и её зависимости с фиксацией версий |
| **Generation** | Снимок системы после каждого `nixos-rebuild`, между которыми можно переключаться |
| **Home Manager** | Инструмент для декларативного управления пользовательскими dotfiles |
| **Overlay** | Механизм переопределения или патчинга пакетов из nixpkgs |
| **Channel** | Классический (не-flake) способ получать nixpkgs определённой версии |
| **Nixpkgs** | Основной репозиторий пакетов и модулей для Nix и NixOS |
| **Module system** | Система модулей NixOS, из которых собирается `configuration.nix` |
| **Garbage collection** | Очистка неиспользуемых путей в `/nix/store` |
| **FHS** | Filesystem Hierarchy Standard — стандартная структура каталогов, которой NixOS сознательно не следует |

> 🚧 _Черновик. Термины будут добавляться по ходу написания гайда._
